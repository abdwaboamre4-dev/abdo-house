## 🚀 Deployment (GitHub Pages — Free Hosting)

This project is 100% static (Vanilla HTML5, CSS3, ES6 JavaScript Modules) and requires **no build step**.

### Quick Steps to Deploy:
1. Create a new GitHub repository (e.g. `abdo-house`).
2. Upload the project files directly to the `main` branch.
3. In your GitHub repository:
   - Go to **Settings** &rarr; **Pages** (on the left menu).
   - Under **Build and deployment** &rarr; **Source**: Select **Deploy from a branch**.
   - Under **Branch**: Select `main` and folder `/ (root)`, then click **Save**.
4. Within 1–2 minutes, your website will be live at:
   `https://<your-username>.github.io/<repository-name>/`
